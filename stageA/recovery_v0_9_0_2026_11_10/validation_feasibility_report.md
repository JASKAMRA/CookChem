# Validation feasibility

| Design | Groups | Decision |
|---|---:|---|
| Random split | records | Not a generalisation claim: correlated rows from a source can appear on both sides. |
| Compound-grouped | 46 | Descriptive molecular extrapolation only; compounds remain source/food clustered. |
| Food-matrix-grouped | 22 | Feasible mechanically, but many foods occur in a single source and test support is heterogeneous. |
| Cooking-method-grouped | 16 | Feasible mechanically but semantically heterogeneous labels and singleton method/source patterns weaken interpretation. |
| Leave-one-source-family-out | 10 | Most honest available broad-domain stress test, but often extrapolation; prior pooled performance is negative. |
| Connected cross-source experimental components | 6 categorical overlap cells | Not sufficient for a valid predictive benchmark: zero strict cross-source protocol replications. |

No new metric is reported because no new evidence was added and a repeated fit would not resolve the validity failure.
