# Experimental target contract

## Target

`apparent_concentration_ratio_percent = 100 × C_cooked / C_raw`

Both concentrations must use the same reported basis within an observed source pair. This target describes measured concentration change, including possible concentration effects of water/solid loss and extraction changes. It is **not** total analyte-mass retention.

## Exclusions

No cooking yield, raw/cooked mass, moisture correction, or cooking-liquid disposition was available for the admitted observations. Therefore no total-mass target is calculated, no value is converted into an analyte-mass multiplier, and no Stage C cooked-exposure integration is authorized.
