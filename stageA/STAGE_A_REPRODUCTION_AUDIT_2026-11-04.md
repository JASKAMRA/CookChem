# Stage A reproduction and integrity audit — 2026-11-04

## Executive result

The Stage A runner completed against the current Git-tracked training input in two isolated Python 3.12.14 environments. The second environment was installed from `stageA/stageA-requirements-py312.lock`. Both runs produced byte-identical OOF predictions and fold assignments. The original stored outputs also align with the current dataset's record IDs, molecular groups and actual target values, and their metrics independently recalculate from their OOF predictions.

**However, the historical and regenerated predictions are not identical.** Regenerated XGBoost RMSE differs by 1.729095, and 1,063/1,124 Extra Trees OOF predictions differ. Historical outputs were preserved; this discrepancy remains a Stage A closure blocker.

- Target: `Retention_Final`; group: `Canonical_Molecular_ID`; seed: 42.
- Target transformation for this independent Stage A comparison: `log1p(y)` in each training fold and `expm1` on predictions before original-scale metrics. - Five-fold `GroupKFold`; five models (Extra Trees reference, Random Forest, RBF-SVR, XGBoost, tuned XGBoost); tuned XGBoost uses inner three-fold grouped selection in each outer training fold.
- No fitted Stage A deployment model or complete Stage A inference package is generated by this benchmark script. Saved OOF predictions are validation outputs, not new-record inference.
