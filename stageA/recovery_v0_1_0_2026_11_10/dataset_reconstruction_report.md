# Dataset reconstruction decision

## Decision: no clean modelling dataset released

All **1124** historical supervised rows are excluded from a new model dataset in this release. This prevents a false impression that arithmetic agreement alone establishes physical retention.

| Evidence status | Rows |
|---|---:|
| DOI_MISMATCH | 18 |
| INSUFFICIENT_EVIDENCE | 807 |
| TARGET_FORMULA_UNRESOLVED | 182 |
| VERIFIED | 117 |

## Why no model was trained

The only verified subset has 117 observations across 24 molecular groups and represents apparent concentration ratios. It lacks yield/mass data and cannot support total-mass cooking exposure. The remaining rows require source-by-source reconstruction before they can be included in any scientifically defined target family.
