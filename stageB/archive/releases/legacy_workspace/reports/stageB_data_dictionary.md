# Stage B data dictionary

Blank cells mean unavailable, uncertain or not reliably extracted, never zero or evidence of absence. UTF-8 CSV. Lists use ` | `; units remain in text. Food/drug/interaction/processing keys are local database identifiers. Source metadata, manual extraction and model outputs remain separate.
