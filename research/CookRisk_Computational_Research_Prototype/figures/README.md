# Curated Figures

Six selected existing analysis figures are copied byte-for-byte from their recorded Stage A paths for convenient viewing in this package. Originals were not modified and no plot was regenerated. Exact source path, SHA-256 equality check, dataset/target, validation context, and limitation are recorded in `FIGURE_SELECTION.csv`. These are REPORTED figures, not newly reproduced results. Figure 2 shows the top 15 of 32 DOI families, not all families. Figure 3 displays fold-wise R²; one molecular-grouped fold is positive, while separately reported pooled R² is negative for both designs. Figures 3–5 derive from an audit whose recorded input hash (111064cee20b1f1536337e95b22941c5d6a07ef71360aad0df0acdbcafe669c8) differs from the current Batch021 CSV hash (d866d0ffab8c335e0469f2815c3cdf518b3d019be1bdf2e37ba2ced2e7d5d3c1); exact historical input bytes were not located, so current-snapshot attribution is BLOCKED/UNVERIFIED.
