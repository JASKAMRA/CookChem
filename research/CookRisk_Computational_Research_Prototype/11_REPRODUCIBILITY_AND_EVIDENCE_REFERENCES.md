# Reproducibility and Evidence References

## Assembly status

This package was assembled by copying selected existing reports/tables into a narrative and linking source paths. It involved no experiment, model training, inference, test-suite run, dependency installation, dataset recalculation, or plot generation. The figure assets copied into this package are byte-for-byte copies; their original files were not edited.

## Result classification

- **REPORTED:** saved metrics, reports, tables, OOF records, or plots in the Stage A package.
- **REPRODUCED:** only the prior documented repeatability check for the specific 1,124-row `Retention_Final` benchmark. The Stage A reproduction audit states that two isolated Python 3.12.14 runs generated byte-identical OOF predictions and fold assignments. This assembly did not repeat it; it does not establish ACR-package reproducibility.
- **PROPOSED:** future analyses and experiments in `10_FUTURE_RESEARCH_WORKFLOW.md`.
- **BLOCKED/UNVERIFIED:** historical-vs-regenerated prediction equivalence; current-byte attribution of the Batch021 validation audit; 439-row parent-hash linkage; canonical dataset designation; and strict independent replicated cells. Saved ACR outputs are reported results, not freshly rerun results.
