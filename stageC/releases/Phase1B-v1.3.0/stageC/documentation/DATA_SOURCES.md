# Data sources

Phase 1B v1.3.0 uses the versioned, manifest-verified `StageB_V20_20261103` registry and the source-verified Stage C food-composition records. The package contains 584 food records, 584 mappings and 125 accepted quantitative food-covered compounds out of 130 identity-complete compounds.

Stage A cooking-retention input and Stage B `cooking_retention_evidence.csv` are separate Phase 2 domains. Their values are not raw-food concentration records. The initial Phase 2 ledger preserves primary-source context and distinguishes quantitative reported loss ranges from qualitative extraction/epimerization evidence.
