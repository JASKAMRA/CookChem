# CookRisk Stage C — Phase 1B v1.2.5

Validated successor to Phase1B-v1.2.4. It preserves the accepted Phase1B data: 582 food-composition records, 582 mappings, and **123/130** identity-complete compounds with accepted quantitative ordinary-food or food-ingredient data. Thirteen of 143 registry compounds remain identity-pending.

Batch 119 screened the final seven uncovered identity-complete compounds. No new value met the project's exact-analyte and food-measurement requirements. A commercial-wine Prunin lead is held because the source quantified flavanones with naringenin proxy calibration. The 130 minimum remains seven short.

Prior releases, StageB_V20_20261103 and Phase1-v1.3.0 remain unchanged. This is a validated progress checkpoint, not target-complete closeout.
