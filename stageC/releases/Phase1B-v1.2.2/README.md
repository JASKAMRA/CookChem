# CookRisk Stage C — Phase 1B v1.2.2

Validated successor to Phase1B-v1.2.1. It integrates StageB_V20_20261103 and accepted quantitative ordinary-food evidence through Batch 116: 580 food-composition records, 580 rebuilt mappings, and **121/130** identity-complete compounds with accepted quantitative ordinary-food data. Thirteen of 143 registry compounds remain identity-pending.

Batch 115 retains the NHDC hard-candy market-survey category summary (11 ± 10 mg/kg; three detections, only one above LOQ), with censoring and LOQ/2 imputation disclosed. Batch 116 adds one red-clover leaf irilone literature summary (0.06 mg/g dry weight). That number is explicitly transcribed from the American Herbal Pharmacopoeia Red Clover monograph, which attributes it to Tsao et al. 2006; the primary study's numerical table was not directly accessible in this review. It is not sample-specific. Nine identity-complete compounds still lack accepted ordinary-food measurements; the 130 minimum is not achieved.

Phase1B-v1.2.1, Phase1-v1.3.0, and StageB V20 remain unchanged. This is a validated progress checkpoint, not a target-complete closeout.
