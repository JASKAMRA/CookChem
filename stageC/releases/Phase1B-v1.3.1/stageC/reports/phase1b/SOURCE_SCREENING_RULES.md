# Phase 1B source screening rules

1. Prefer authoritative food-composition datasets and primary analytical results that name the analyte and edible food matrix.
2. Accept values only where Stage B identity is complete, an exact identifier/name mapping is supportable, food state and fresh/dry basis are explicit, source record and units are traceable, and the value is positive/source-documented.
3. USDA summary values are accepted only as USDA database-derived weighted means, never relabelled as single-study measurements. Retain N, SEM, min/max, confidence code, NDB, table locator, and source-reference IDs in notes.
4. USDA documentation says catechin/epicatechin flavan-3-ols are reported under their analyte names without the glycoside-to-aglycone conversion used for many other flavonoids; use exact stereospecific Stage B IDs.
5. Hold quercetin candidate values because aglycone-equivalent database semantics may include native glycosides. Hold tea candidate values until a compatible beverage/standardized-infusion basis is represented.
6. Do not admit Stage B identity-pending records, supplements, medicinal botanicals, or ambiguous analytes as verified food mappings.
7. Missing values remain missing; database-reported zero is a separate measurement result and is never substituted for missing data.

Checkpoint 1 priority rules are operational, not a safety ranking: P1 = accepted verified record; P2 = located source/candidate needing review; P3 = plausible food-associated context without quantitative record; P4 = supplement/medicinal context; P5 = no reliable dietary context identified.
