# CookRisk Stage C — Phase 1B v1.2.8

Validated successor to Phase1B-v1.2.5. It contains 584 food-composition records, 584 rebuilt mappings, and **125/130** identity-complete compounds with accepted quantitative ordinary-food or food-ingredient data. Thirteen of 143 registry compounds remain identity-pending.

Batch 120 adds amentoflavone at 3.88 ± 0.11 mg/100 g in Maazoun melon seed oil. The primary HPLC source used phenolic standards; the oil was evaluated as edible and for culinary/food-formulation use. This is one experimental cultivar sample, with triplicate analytical determinations. Batch 122 adds Prunin in Rihua5 peach pulp at 33.333 μg/g fresh weight using an authentic standard and its own calibration curve. Batch 123 re-screened the five remaining gaps but found no new qualifying quantitative values. Coverage remains 125/130, so the 130 minimum is not achieved. See `stageC/reports/phase1b/batches/batch_123_six_gap_recheck/SCREENING_REPORT.md` for decisions and source links.
