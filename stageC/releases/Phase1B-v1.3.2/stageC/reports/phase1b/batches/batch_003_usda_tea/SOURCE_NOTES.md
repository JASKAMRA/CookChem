# USDA Release 3.3 tea extraction notes — batch 003

Accepted table row: NDB 99069, “Tea, green, brewed, decaffeinated,” summary table printed p.105 / PDF p.107. USDA reports (-)-Epigallocatechin 3-gallate at 26.05 mg/100g (100ml); N=2, SE=0.69, min=25.36, max=26.73, confidence B, source ref 272. The USDA reference list identifies ref 272 as Unilever Bestfoods North America, *Summary Flavonoid Content of Teas in the U.S. Market*, unpublished data (2002). USDA documentation states tea infusion values are standardized to 1% tea leaves (1g/100ml boiling water), reported as consumed, and states catechin gallate esters are not glycoside-to-aglycone converted.

The same NDB 99069 table row reports Theaflavin at 0.12 mg/100g (100ml); N=2, SE=0.08, min=0.04, max=0.20, confidence B, source ref 272. It is retained as the exact USDA analyte label, mapped to Stage B Theaflavin; the reported value remains an as-consumed standardized infusion result.

Both compounds are accepted as source-verified USDA database aggregates for the reported analyte labels and stated standardized prepared beverage. The underlying unpublished observations and analytical method cannot be independently checked; low N and source limitations remain prominent. No DOI, PMID, CID, or method was fabricated. No dry-tea mass is inferred from the serving; exposure applies only to the stated infusion basis.
