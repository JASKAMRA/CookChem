# Batch 112 — Huangqin aerial-leaf flavones

Four measured leaf analytes were added to the successor: scutellarein (340 mg/kg FW), baicalein (90 mg/kg FW), wogonin (10 mg/kg FW), and wogonoside (270 mg/kg FW). The source reports *Scutellaria baicalensis* leaves, fresh-weight values, five biological replicates, HPLC-DAD, authentic standards, and external standard curves (Costine et al., 2022, Table 2; [primary article](https://doi.org/10.1038/s41598-022-17586-1)).

Food-use scope is limited to the aerial parts used as Huangqin tea; the measured values are raw leaf tissue, not brewed tea. A review documents Huangqin tea as an aerial-part beverage with a traditional preparation process ([review](https://doi.org/10.48130/BPR-2023-0031)). The root-based medicinal values in the same paper were excluded. Batch 112 raised unique accepted coverage from 115 to 119. This batch is in Phase1B v1.2.0; the 130 target remains unmet.
