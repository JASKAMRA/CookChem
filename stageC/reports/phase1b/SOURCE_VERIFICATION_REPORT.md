# Source verification report

Primary source inspected: USDA ARS, *Database for the Flavonoid Content of Selected Foods*, Release 3.3 official summary PDF (2018). All four accepted values were verified directly against the official summary tables and classified as authoritative food-composition database records. Each accepted row preserves USDA NDB, table locator, mg/100g edible-portion unit, mean, N, SE, range, confidence code, and source-reference IDs. The underlying Access database and individual source publications behind refs 8, 105 and apple table refs were not independently inspected. Accordingly, these are source-verified USDA aggregate means, not individually replicated primary-study measurements. Quercetin and tea EGCG remain excluded pending method/basis decisions.
