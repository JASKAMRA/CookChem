# Stage C Phase 1 and Phase 1B handoff

Phase 1 is the preserved software foundation: read-only Stage B integration, source-backed food composition, conservative mapping, unit normalization, raw-food arithmetic, validation and provenance. Its repository-root release `Phase1-v1.3.0` remains connected to the protected `StageB_FINALIZED` snapshot.

The latest Phase 1B scientific successor is `releases/Phase1B-v1.3.0/`, which uses `StageB_V20_20261103`. It contains 143 compounds, 130 identity-complete and 13 identity-pending; 584 food records and mappings; and 125/130 accepted quantitative ordinary-food coverage. The user accepted Phase 1B closure at this count. The approximate 120 target is met; the 130 minimum remains five short. Five gaps remain documented.

Phase 2 is underway in repository-root `stageC/phase2/`. The current increment includes individually dispositioned identity candidates, observed-retention evidence, guarded interval arithmetic, and 117 source-transcribed raw/cooked concentration pairs from two primary studies. A Stage B Extra Trees candidate is frozen, but its manifest input hash differs from the current Stage A data and the needed runtime packages are unavailable, so no new-record inference is being made. OOF predictions remain validation outputs. Retention evidence must not be applied to a food concentration unless compound identity, matrix, cooking conditions and analytical basis are compatible. No Phase 1B value is modified by Phase 2.
